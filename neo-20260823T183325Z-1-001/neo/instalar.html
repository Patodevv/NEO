O mesmo NEO, dentro do aplicativo.

O computador mantém o sistema e o banco de dados. O aplicativo Android abre esta mesma versão do NEO, com a mesma conta e os mesmos conteúdos.

Baixar APK para Android
  1. Conecte o celular e o computador à mesma rede Wi-Fi.
  2. Mantenha o Apache e o MySQL ligados no XAMPP.
  3. Se uma versão anterior do NEO Remoto já estiver instalada, desinstale-a uma única vez. A conta e os dados salvos no computador não serão apagados.
  4. Baixe e instale o APK. Se o Android solicitar, permita a instalação por este navegador.
  5. Abra o NEO Remoto e informe o endereço abaixo. Se o IP mudar depois, toque no botão IP, sempre visível no canto superior direito.
