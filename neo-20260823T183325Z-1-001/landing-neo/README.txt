LANDING PAGE NEO

1. Publique todos os arquivos desta pasta mantendo a estrutura de pastas.
2. A página inicial é o arquivo index.html.
3. Depois da publicação, copie a URL final, por exemplo:
   https://seu-dominio.com/
4. Gere o QR Code usando essa URL e substitua o QR placeholder do cartão.

Esta landing page é estática: funciona em hospedagem comum, sem PHP, banco de dados ou instalação.
